# 🧁 PanaderiaApp

## 📘 Descripción del proyecto

**PanaderiaApp** es una aplicación de escritorio modular diseñada para la gestión integral de una panadería. El sistema está construido con tecnologías modernas como Electron.js, Node.js, Express y MongoDB, y está estructurado en componentes independientes que facilitan su mantenimiento y escalabilidad.

---

## 📦 Estructura del proyecto

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js + Express  
- **Base de datos:** MongoDB (Mongoose)  
- **Empaquetado:** Electron Builder (`PanaderiaApp Setup 1.0.0.exe`)  
- **Control de versiones:** Git + GitHub  

---

## 🧱 Arquitectura modular

El proyecto está organizado en carpetas que representan cada componente funcional:

- `/controladores` — Lógica de negocio y validaciones  
- `/modelos` — Esquemas de MongoDB  
- `/rutas` — Endpoints para cada módulo  
- `/frontend` — Interfaz de usuario  
- `/main.js` — Punto de entrada para Electron (inicia backend y frontend)
